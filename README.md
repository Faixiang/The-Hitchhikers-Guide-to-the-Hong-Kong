# The Hitchhiker's Guide to the Hong Kong

> 香港萬遊指南 — 遊戲化香港旅遊攻略站。把香港當攻略來打，**打卡為輸入，角色成長為呈現**。

**狀態**：策劃中（尚未技術選型） · **性質**：開源、非商業
**倉庫名致敬** Douglas Adams《The Hitchhiker's Guide to the Galaxy》；僅作個人專案命名，不涉商業用途。

---

## 這是什麼

一個以「探索度」為核心玩法的香港深度遊指南。使用者走訪景點／店舖並打卡，累積的不是清單的長度，而是一張會成長的角色卡。

核心循環：

```
探索 → 打卡 → 獲得 XP → 升等 / 解鎖徽章 → 看見「還沒去的地方」 → 再探索
```

## 已定調的六項決策

| # | 項目 | 結論 |
|---|---|---|
| 1 | 專案性質 | 遊戲化旅遊攻略站（非純工具、非純內容站） |
| 2 | 玩法骨架 | 兩者疊加：打卡（副本層）＋ 角色成長（RPG 層），打卡是輸入、角色是呈現 |
| 3 | 內容軸線 | 雙軸並行：行政區作索引、主題路線作遊玩動線 |
| 4 | 打卡驗證 | GPS 半徑為主，定位失敗或室內可手動補登 |
| 5 | 目標受眾 | 雙受眾並行：首次訪港旅客 ＋ 本地深度探索者 |
| 6 | 專案正名 | 香港萬遊指南（「萬遊」＝眾多旅程，非「萬游」） |
