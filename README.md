## 這是什麼

一款以「探索度」為核心玩法的香港深度遊指南。使用者走訪景點與店舖並打卡，累積的不是清單的長度，而是一張會成長的角色卡。

```
探索 → 打卡 → 獲得 XP → 升等 / 解鎖徽章 → 看見「還沒去的地方」 → 再探索
```

## 特色

- 🗺️&nbsp;以行政區作索引、主題路線作遊玩動線，雙軸並行。
- 📍&nbsp;GPS 半徑打卡為主；定位失敗或室內可手動補登。
- 🎮&nbsp;打卡即輸入，角色卡、等級與 XP 即呈現。
- 🏅&nbsp;成就徽章與收集進度，讓「去過哪」變成可展示的成果。
- 🧭&nbsp;雙受眾並行：首次訪港旅客與本地深度探索者共用同一份點位資料。
- 🀄&nbsp;全繁體中文編寫，地名保留香港原生寫法。

## 狀態

本專案處於**策劃階段**，尚未技術選型。

| # | 項目 | 結論 |
|---|---|---|
| 1 | 專案性質 | 遊戲化旅遊攻略站（非純工具、非純內容站） |
| 2 | 玩法骨架 | 打卡（副本層）＋ 角色成長（RPG 層）疊加 |
| 3 | 內容軸線 | 行政區（索引）＋ 主題路線（動線）雙軸 |
| 4 | 打卡驗證 | GPS 半徑為主，手動補登為輔 |
| 5 | 目標受眾 | 首次訪港旅客 ＋ 本地深度探索者 |
| 6 | 專案正名 | 香港萬遊指南（「萬遊」＝眾多旅程） |
